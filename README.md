# Dash E-commerce Dashboard

Este projeto é uma aplicação web interativa construída com [Dash](https://dash.plotly.com/) e [Plotly](https://plotly.com/python/), que permite visualizar dados de um dataset de e-commerce. O objetivo é oferecer uma interface simples e dinâmica para explorar informações como marcas, materiais, preços e notas dos produtos.

##  Funcionalidades
- Histograma de distribuição por **Marca**
- Histograma de distribuição por **Material**
- Gráfico de dispersão relacionando **Preço** e **Nota**
- Interface interativa acessível via navegador

##  Tecnologias utilizadas
- Python 3.x
- Dash
- Plotly
- Pandas
